

# 🏆 OVRIXA

**OVRIXA** is a modern sports brand focused on combining athletic performance, comfort, and contemporary design. From performance-driven sportswear to essential sporting equipment, our mission is to help athletes and sports enthusiasts move with confidence and perform at their best.


## 🛍️ Product Categories

| 🏷️ Category | ⚡ Products |
|:---|:---|
| 👕 Sportswear | Jerseys, Hoodies & Training Wear |
| ⚽ Football | Footballs, Boots & Accessories |
| 🏏 Cricket | Bats, Batting Pads & Equipment |
| 👟 Footwear | Sports Shoes & Performance Footwear |
| 🎒 Accessories | Essential Sports Gear |

## 🎨 Brand Identity

- 🖤 **Primary Style:** Clean, modern & athletic
- 💚 **Accent Color:** Electric Lime `#C8FF00`
- 🤍 **Core Colors:** Black & White
- ⚡ **Brand Tagline:** PLAY BEYOND.

## 🎯 Our Vision

To build a recognizable sports brand that inspires people to stay active, embrace competition, and push beyond their limits.

## 🛠️ Tech Stack

Technologies planned for the digital storefront:

- 💻 **Frontend:** React / HTML / CSS / JavaScript
- 🎨 **Styling:** Tailwind CSS
- ⚙️ **Backend:** Node.js & Express.js
- 🗄️ **Database:** MongoDB
- 🔧 **Version Control:** Git & GitHub

## 🚀 Getting Started

To run the project locally, follow these steps:

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd ovrixa
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

> Make sure Node.js is installed. These commands assume a Node.js-based project.
